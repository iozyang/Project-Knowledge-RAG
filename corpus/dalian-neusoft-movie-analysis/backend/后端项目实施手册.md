## 1. 项目简介

### 1.1 项目背景

电影分析管理平台是一个基于豆瓣电影数据的大数据分析项目，整体数据链路为：

```
豆瓣电影原始数据 → PySpark（Spark Core / SparkSQL）统计分析
    → 结果 CSV 落盘 HDFS（/movies/analysis_results/）
    → Sqoop 导出至 MySQL（movie_stat_db）
    → 本后端 API 提供 REST 查询服务
    → 前端 / ECharts 可视化展示
```

本项目 **MovieAnalysisAPI** 即该平台的 Web 后端，负责读取 MySQL 中的统计分析结果，并以统一的 RESTful JSON 接口对外提供查询服务，支撑前端 ECharts 图表（柱状图、饼图、折线图、热力图、排行榜等）的数据展示。

### 1.2 技术架构

| 分层 | 技术 | 说明 |
|------|------|------|
| Web 层 | Spring Boot Web（Spring MVC + 内嵌 Tomcat） | REST API |
| 业务层 | Spring Service | 查询参数校验、业务封装 |
| 持久层 | MyBatis-Plus | BaseMapper + QueryWrapper，无需手写 SQL |
| 数据库 | MySQL（movie_stat_db，utf8mb4） | 13 张统计结果表 |
| 构建 | Maven（mvnw wrapper） | 打包为 war |

### 1.3 功能清单（13 个统计接口模块）

| 编号 | 模块（表名） | 统计内容 | 可视化建议 |
|------|-------------|---------|-----------|
| 1 | `stat_movie_year` | 每年电影数量 | 折线/柱状图 |
| 2 | `stat_high_score_avg` | 高分电影（评分≥7.5）平均分 | 指标卡 |
| 3 | `stat_mins_total` | 片长最长/最短/平均 | 指标卡 |
| 4 | `stat_region_count` | 各地区电影数量 | 柱状图 |
| 6 | `stat_score_section` | 评分区间电影数量 | 饼图 |
| 7 | `stat_region_top50` | 地区发行量 Top50 | 条形图 |
| 8 | `stat_year_region_count` | 每年各国发行量（年份×地区） | 堆叠柱状图/热力图 |
| 9 | `stat_region_year_avg_score` | 各国每年平均评分 | 折线图 |
| 10 | `stat_language` | 各语言电影数量 | 柱状图 |
| A | `stat_genre_count` | 各电影类型数量 | 饼图/柱状图 |
| B | `stat_year_top20_movie` | 每年豆瓣评分 Top20 电影 | 排行榜/条形图 |

| F | `stat_year_avg_mins` | 各年代平均片长趋势 | 折线图 |

> 注：功能 5（SparkSQL 版按年份统计电影数量）仅注册临时视图、不落盘，故无对应表与接口。

## 3. 本地部署流程

### 3.1 前置条件检查

1. 已安装 JDK 17 并配置 `JAVA_HOME`：

   ```cmd
   java -version
   # 应输出类似: openjdk version "17.x.x"
   ```

2. 可用的 MySQL 8.x 实例（本机或远程虚拟机均可）。

### 3.2 初始化数据库

在 MySQL 服务器上执行项目根目录下的建库建表脚本（脚本自带 `CREATE DATABASE`，无需手工建库）：

```bash
# 方式一：命令行执行
mysql -u<user> -p < movie_stat_db.sql

# 方式二：登录 MySQL 后执行
mysql -u<user> -p
mysql> source /path/to/MovieAnalysisAPI/movie_stat_db.sql
```

> 注意：
> - 脚本共创建 13 张表，表结构字段顺序与 Spark 统计结果列顺序一致，**不可调整**。
> - 建表后需通过 Sqoop（`--fields-terminated-by ','`）或手工方式将 HDFS 上的统计结果 CSV 导入各表，表中有数据接口才有返回内容。

### 3.3 修改数据源配置

编辑 `src/main/resources/application.yml`，将连接地址、账号、密码改为本地实际值：

```yaml
spring:
  application:
    name: MovieAnalysisAPI
  datasource:
    url: jdbc:mysql://<MySQL主机IP>:3306/movie_stat_db?useUnicode=true&characterEncoding=UTF-8
    username: <用户名>        # 如 root
    password: <密码>          # 如 root
mybatis-plus:
  type-aliases-package: org.neusoft.movieanalysisapi.entity
  configuration:
    map-underscore-to-camel-case: true      # 下划线列 -> 驼峰属性
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl   # 控制台打印 SQL
  global-config:
    db-config:
      id-type: none
```

### 3.4 启动应用

**方式一：IDEA 中启动（推荐开发期使用）**

1. 用 IDEA 打开项目根目录，等待 Maven 依赖索引完成；
2. 运行主类 `org.neusoft.movieanalysisapi.MovieAnalysisApiApplication`。

**方式二：Maven 命令启动（无需安装 Maven，使用内置 Wrapper）**

```cmd
cd /d d:\workspace\idea\MovieAnalysisAPI
mvnw.cmd spring-boot:run
```

**方式三：打包 war 后运行**

```cmd
mvnw.cmd clean package -DskipTests
java -jar target\MovieAnalysisAPI-0.0.1-SNAPSHOT.war
```

> 项目打包类型为 `war`，同时包含 `ServletInitializer`，因此也支持传统方式部署到外部 Tomcat（需 Tomcat 11+，与 Jakarta EE 版本匹配）。

### 3.5 验证部署

浏览器或 curl 访问任一接口，确认返回统一 JSON 结构：

```bash
curl http://localhost:8080/statMovieYear/listAll
```

预期响应：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    { "movieYear": 2019, "movieCount": 400 },
    { "movieYear": 2020, "movieCount": 450 }

```

### 3.6 常见问题排查

| 现象 | 原因与处理 |
|------|-----------|
| 启动报 `Communications link failure` | 数据源 IP/端口/账号错误，或 MySQL 未开放远程访问（检查 `bind-address`、防火墙、用户 host 授权） |
| 接口返回 `data` 为空数组 | 对应统计表无数据，需先通过 Sqoop 导入 HDFS 统计结果 |
| 中文乱码 | 确认连接串带 `characterEncoding=UTF-8`，且库为 `utf8mb4` |
| 端口占用 | `server.port` 前提下加 `-Dserver.port=8081` 启动，或停掉占用进程 |

### 4.2 阶段二：编写代码

按照 "统一响应 → 实体 → Mapper → 分页插件 → Service → Controller → 异常处理" 的顺序实施。下面以 **功能 1（每年电影数量，表 `stat_movie_year`）** 为例给出完整代码，其余 12 个模块按同一模式实现。

#### 4.2.1 统一响应结构（commons/Result.java）

所有接口统一返回 `code / message / data / timestamp` 四段结构，成功码为 `0`：

```java
@Data
public class Result<T> {
    private Integer code;
    private String message;
    private T data;
    private Long timestamp;

    public Result() { this.timestamp = System.currentTimeMillis(); }

    public Result(Integer code, String message, T data, Long timestamp) {
        this.code = code; this.message = message;
        this.data = data; this.timestamp = timestamp;
    }

    public static <T> Result<T> success(T data) {
        return new Result<>(0, "success", data, System.currentTimeMillis());
    }

    public static Result<Void> error(int code, String message) {
        return new Result<>(code, message, null, System.currentTimeMillis());
    }
}
```

#### 4.2.2 实体类（entity/StatMovieYear.java）

每张统计表对应一个实体，用 `@TableName` 指定表名、`@TableId(type = IdType.INPUT)` 标注查询主键，并利用 `map-underscore-to-camel-case` 完成下划线列到驼峰属性的自动映射。类头注释保留对应建表 SQL 便于对照：

```java
@Data
@TableName("stat_movie_year")
public class StatMovieYear {
    @TableId(type = IdType.INPUT)
    private Integer movieYear;
    private Long movieCount;
}
```

> 13 个实体类与 13 张表一一对应，如 `StatHighScoreAvg`、`StatMinsTotal`、`StatRegionCount`、`StatScoreSection`、`StatRegionTop50`、`StatYearRegionCount`、`StatRegionYearAvgScore`、`StatLanguage`、`StatGenreCount`、`StatYearTop20Movie`、`StatActorTop50`、`StatYearAvgMins`。

#### 4.2.3 Mapper 接口（mapper/StatMovieYearMapper.java）

继承 MyBatis-Plus 的 `BaseMapper` 即可获得 `selectList / selectPage / selectCount` 等通用 CRUD，无需编写 XML：

```java
public interface StatMovieYearMapper extends BaseMapper<StatMovieYear> {
}
```

#### 4.2.4 MyBatis-Plus 分页插件配置（interceptor/MyBatisPlusConfig.java）

```java
@Configuration
public class MyBatisPlusConfig {

    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }
}
```

#### 4.2.5 Service 层（service + service/impl）

接口 `StatMovieYearService` 继承 MyBatis-Plus 的 `IService`，实现类继承 `ServiceImpl` 并用构造器注入方式供 Controller 使用。查询条件通过 `QueryWrapper` 构建，公共参数校验收敛到 `ServiceQueryChecks` 工具类（对年份范围、分页参数等做前置校验，校验失败抛出 `IllegalArgumentException`）：

```java
@Service
public class StatMovieYearServiceImpl
        extends ServiceImpl<StatMovieYearMapper, StatMovieYear>
        implements StatMovieYearService {

    @Override
    public List<StatMovieYear> listAll() {
        return baseMapper.selectList(new QueryWrapper<StatMovieYear>().orderByAsc("movie_year"));
    }

    @Override
    public List<StatMovieYear> listByYearRange(Integer startYear, Integer endYear) {
        ServiceQueryChecks.yearRange(startYear, endYear);
        return baseMapper.selectList(new QueryWrapper<StatMovieYear>()
                .between("movie_year", startYear, endYear)
                .orderByAsc("movie_year"));
    }
}
```

#### 4.2.6 Controller 层（controller/StatMovieYearController.java）

`@RestController` + `@GetMapping`，返回值统一包装为 `Result<T>`；Service 采用构造器注入（非 `@Autowired` 字段注入）：

```java
@RestController
@RequestMapping("/statMovieYear")
public class StatMovieYearController {
    private final StatMovieYearService statMovieYearService;

    public StatMovieYearController(StatMovieYearService statMovieYearService) {
        this.statMovieYearService = statMovieYearService;
    }

    @GetMapping("/listAll")
    public Result<List<StatMovieYear>> listAll() {
        return Result.success(statMovieYearService.listAll());
    }

    @GetMapping("/listByYearRange")
    public Result<List<StatMovieYear>> listByYearRange(
            @RequestParam("startYear") Integer startYear,
            @RequestParam("endYear") Integer endYear) {
        return Result.success(statMovieYearService.listByYearRange(startYear, endYear));
    }
}
```

> 其余模块的 URL 前缀按驼峰实体名命名，如 `/statGenreCount`、`/statYearTop20Movie`、`/statActorTop50` 等；除 `listAll` 外，按各表维度提供 `listByYearRange`、`listByPage`、Top 榜单等条件查询接口。

#### 4.2.7 全局异常处理（controller/ApiExceptionHandler.java）

`@RestControllerAdvice` 统一拦截 Controller 层异常，转为 `Result` 结构并返回 400 状态码：

```java
@RestControllerAdvice(basePackages = "org.neusoft.movieanalysisapi.controller")
public class ApiExceptionHandler {

    @ExceptionHandler(IllegalArgumentException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Result<Void> invalidArgument(IllegalArgumentException e) {
        return Result.error(400, e.getMessage());
    }

    @ExceptionHandler(MissingServletRequestParameterException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Result<Void> missingParameter(MissingServletRequestParameterException e) {
        return Result.error(400, "Missing required parameter: " + e.getParameterName());
    }

    @ExceptionHandler(MethodArgumentTypeMismatchException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Result<Void> invalidParameterType(MethodArgumentTypeMismatchException e) {
        return Result.error(400, "Invalid parameter type: " + e.getName());
    }
}
```

#### 4.2.8 编码规约小结

- 分层：`controller → service(接口) → service/impl → mapper → entity`，禁止跨层调用；
- 响应：所有接口统一返回 `Result<T>`，成功 `code=0`；
- 注入：统一构造器注入；
- 校验：公共查询参数校验集中在 `ServiceQueryChecks`；
- SQL：全部通过 MyBatis-Plus `QueryWrapper` / `BaseMapper` 完成，无 XML 映射文件。

### 4.3 阶段三：编写测试用例

测试分为四个层次，共 57 个测试类，均基于 JUnit 5 编写，配合 `@DisplayName` 中文用例说明。

#### 4.3.1 Controller 层单元测试（MockMvc + Mockito）

特点：`@ExtendWith(MockitoExtension.class)` Mock 掉 Service，`standaloneSetup` 挂载被测 Controller 并注册全局异常处理器，不依赖数据库、不启动 Spring 容器：

```java
@ExtendWith(MockitoExtension.class)
class StatMovieYearControllerTest {

    @Mock
    private StatMovieYearService statMovieYearService;

    @InjectMocks
    private StatMovieYearController statMovieYearController;

    private MockMvc mvc;

    @BeforeEach
    void setUp() {
        mvc = MockMvcBuilders.standaloneSetup(statMovieYearController)
                .setControllerAdvice(new ApiExceptionHandler())
                .build();
    }

    @Test
    @DisplayName("listAll 返回统一成功结构")
    void listAllReturnsSuccessResult() throws Exception {
        when(statMovieYearService.listAll())
                .thenReturn(List.of(buildYear(2019, 400L), buildYear(2020, 450L)));

        mvc.perform(get("/statMovieYear/listAll"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.code").value(0))
                .andExpect(jsonPath("$.message").value("success"))
                .andExpect(jsonPath("$.data.length()").value(2))
                .andExpect(jsonPath("$.data[0].movieYear").value(2019));

        verify(statMovieYearService).listAll();
    }
}
```

典型覆盖场景：

- 正常返回数据、空数据（`data` 为空数组）；
- 必填参数缺失（400 + `Missing required parameter`）；
- 参数类型不匹配（400 + `Invalid parameter type`）；
- 业务参数非法（Service 抛 `IllegalArgumentException` 时返回 400 与错误信息）。

#### 4.3.3 Mapper 层集成测试（@SpringBootTest）

连接真实数据库验证 MyBatis-Plus 通用 CRUD 与分页插件。断言先查总数再动态比较，避免写死数据量导致用例脆弱：

```java
@SpringBootTest(classes = MovieAnalysisApiApplication.class)
public class StatMovieYearMapperTest {

    @Autowired
    private StatMovieYearMapper statMovieYearMapper;

    @Test
    @DisplayName("分页查询数据")
    void testSelectByPage() {
        long total = statMovieYearMapper.selectCount(null);

        int size = 5;
        Page<StatMovieYear> result = statMovieYearMapper.selectPage(new Page<>(1, size), null);

        assertNotNull(result);
        assertEquals(total, result.getTotal());
        assertEquals((total + size - 1) / size, result.getPages());
        assertEquals((int) Math.min(size, total), result.getRecords().size());
    }

    @Test
    @DisplayName("查询全部数据")
    void testSelectAll() {
        List<StatMovieYear> list = statMovieYearMapper.selectList(null);

        assertNotNull(list);
        assertFalse(list.isEmpty());
        list.forEach(row -> {
            assertNotNull(row.getMovieYear());
            assertTrue(row.getMovieYear() >= 0 && row.getMovieYear() <= 2100);
            assertTrue(row.getMovieCount() > 0);
        });
    }
}
```
