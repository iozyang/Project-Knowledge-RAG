# 电影大数据分析与智能推荐系统 - 前端实施方案

## 1. 项目概述

### 1.1 项目背景

本项目是一个基于豆瓣电影数据的大数据分析与可视化平台，旨在通过直观的图表和数据分析，帮助用户深入了解电影市场趋势、评分分布、地域特征等关键信息。

### 1.2 项目目标

- 提供直观的电影数据可视化展示
- 支持多维度的数据分析与探索
- 实现响应式设计，适配多种屏幕尺寸
- 提供良好的用户体验和交互设计

### 1.3 核心功能

- **用户认证**：安全的登录机制与密码管理
- **数据可视化**：12个不同维度的图表展示
- **实时展示**：实时时间显示与LIVE状态指示
- **主题切换**：深色/浅色/跟随系统三种主题模式
- **自适应布局**：支持大屏展示和小屏访问

## 3. 核心模块实现

### 3.1 路由管理

#### 3.1.1 路由配置

```javascript
// src/router/index.js
const routes = [
  {
    path: '/',
    redirect: '/login'
  },
  {
    path: '/login',
    component: Login
  },
  {
    path: '/dashboard',
    component: Dashboard,
    meta: { requiresAuth: true }  // 需要认证
  }
]
```

#### 3.1.2 路由守卫

实现基于 Token 的认证机制：

- 检查 `localStorage` 中的 token
- 验证 token 中包含的密码版本
- 无效 token 自动跳转登录页
- 已登录用户访问登录页自动跳转仪表板

### 3.2 用户认证

#### 3.2.1 登录流程

```
1. 用户输入用户名、密码
2. Canvas 生成验证码
3. 前端验证验证码
4. 验证用户名和密码
5. 生成包含密码版本的 token
6. 存储到 localStorage
7. 跳转到仪表板
```

#### 3.2.2 密码管理

- 默认密码：`[REDACTED]`
- 支持密码修改功能
- 密码修改后自动清除登录状态
- 密码存储在 `localStorage`

#### 3.2.3 验证码实现

使用 Canvas 绘制验证码：

- 4位随机字符（字母+数字）
- 随机颜色和旋转角度
- 干扰线和噪点
- 点击刷新功能

### 3.3 API 请求封装

#### 3.3.1 请求配置

```javascript
// src/api/request.js
const request = axios.create({
  baseURL: API_BASE_URL,
  timeout: 10000,
  validateStatus: () => true  // 捕获所有 HTTP 状态码
})
```

#### 3.3.2 统一响应处理

- 统一响应结构：`{ code, message, data, timestamp }`
- `code === 0` 视为业务成功
- 统一错误处理机制
- 网络错误、超时、业务错误分类处理

#### 3.3.3 Base URL 配置

支持两种配置方式：

1. 环境变量：`VITE_API_BASE_URL`
2. 自动构造：`http://${hostname}:8080`

### 3.4 主题管理

#### 3.4.1 主题模式

支持三种主题模式：

- **深色模式（dark）**：适合夜间使用
- **浅色模式（light）**：适合日间使用
- **跟随系统（system）**：根据系统设置自动切换

#### 3.4.2 实现机制

```javascript
// src/composables/useTheme.js
export function useTheme() {
  function toggleTheme() {
    const next = (MODES.indexOf(themeMode.value) + 1) % MODES.length
    themeMode.value = MODES[next]
  }
  
  return { themeMode, resolvedTheme, toggleTheme }
}
```

#### 3.4.3 CSS 变量

使用 CSS 变量实现主题切换：

```css
:root {
  --text-primary: /* 主题相关颜色 */
  --bg-panel: /* 主题相关背景 */
  --border-primary: /* 主题相关边框 */
}
```

### 3.6 响应式设计

#### 3.6.1 屏幕适配策略

**大屏设备（≥1024px）**：
- 使用 `autofit.js` 进行等比缩放
- 基于设计稿 1920x1080
- 保持布局比例不变

**小屏设备（<1024px）**：
- 跳过 autofit 缩放
- 使用响应式流式布局
- 保证基本可用性

#### 3.6.2 断点设计

```css
/* 大屏 */
@media (min-width: 1024px) {
  /* autofit 自动缩放 */
}

/* 中屏 */
@media (max-width: 1023px) {
  .metrics-grid {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}

/* 小屏 */
@media (max-width: 767px) {
  .metrics-grid {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
  .dashboard-grid {
    grid-template-columns: minmax(0, 1fr);
  }
}
```

### 5.2 生产环境

#### 5.2.1 构建打包

```bash

npm run build

# 预览构建结果
npm run preview
```

#### 5.2.2 部署配置

1. **Nginx 配置**

```nginx
server {
  listen 80;
  server_name your-domain.com;
  
  root /path/to/dist;
  index index.html;
  
  location / {
    try_files $uri $uri/ /index.html;
  }
  
  # API 代理
  location /api/ {
    proxy_pass http://backend:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }
}
```

2. **Apache 配置**

```apache
<VirtualHost *:80>
  DocumentRoot /path/to/dist
  ServerName your-domain.com
  
  <Directory /path/to/dist>
    Options Indexes FollowSymLinks
    AllowOverride All
    Require all granted
    
    RewriteEngine On
    RewriteBase /
    RewriteRule ^index\.html$ - [L]
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule . /index.html [L]
  </Directory>
</VirtualHost>
```

#### 5.2.3 CDN 部署

将构建产物上传到 CDN：

- 静态资源上传到对象存储
- 配置 CDN 加速域名
- 开启 HTTPS
- 配置缓存策略

### 5.3 Docker 部署

#### 5.3.1 Dockerfile

```dockerfile
# 构建阶段
FROM node:18-alpine as builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 运行阶段
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

## 7. 安全方案

### 7.1 前端安全

#### 7.1.1 XSS 防护

- Vue 自动转义插值表达式
- 避免使用 `v-html`
- 对用户输入进行验证

#### 7.1.2 CSRF 防护

- 使用 token 认证
- 验证码机制
- 关键操作二次确认

#### 7.1.3 密码安全

- 前端不存储明文密码（仅演示用）
- 生产环境应使用后端认证
- 密码修改需要验证旧密码

### 7.2 数据安全

#### 7.2.1 敏感数据

- Token 存储在 localStorage
- 敏感操作需要验证
- 定期清理过期数据

#### 7.2.2 API 安全

- HTTPS 传输
- 请求超时控制
- 错误信息脱敏
